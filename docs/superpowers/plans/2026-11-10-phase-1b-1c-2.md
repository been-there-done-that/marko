# Marko — Phases 1b, 1c and 2 Implementation Plan

> **For agentic workers:** work one task at a time: failing tests first, then code, `cargo test` green, one commit. Read `NOTES-1a.md` first: it records how the real Rune APIs differ from what `PLAN.md` assumed.

**Goal:** finish the app side of the viewer (find, images, code copy, links, live reload, tab and menu polish, packaging) and add editing (Edit mode, New, Save, unsaved-changes guard).

**Architecture:** the same crate and patterns as phase 1a. Logic lives in plain modules with unit tests, views stay thin, slow work runs on the worker or the watcher thread and comes back through `AppHandle::update`.

**Spec:** `PLAN.md` §4.3, §4.5, §4.8, §4.11, §4.12, §5.2, §5.3, §5.5, §10, §12. UI reference: `ui-preview.html`.

**Not in this plan:**
- Rune PRs: P0-a/P0-b, P1-a/P1-b, R1–R8 (`PLAN.md` §9). They go to the public Rune repo for someone else's review (D11), so the app keeps its §9.1 fallbacks.
- macOS `.app` and Windows MSIX packaging. They can't be built or checked on the Linux build machine; Linux packaging only.

## Global Constraints

- Everything in the phase 1a plan's Global Constraints still applies: the pinned Rune rev, no `[patch]`, files under 800 lines, sorted `mod` lists, no `std::fs` on the UI thread, `poll` returns true only when visible state changed.
- New dependencies (exact):
  - `notify = { version = "8", default-features = false, features = ["macos_fsevent"] }`
  - `image = { version = "0.25", default-features = false, features = ["png", "jpeg", "gif", "webp"] }`
  - `blake3` is not added: use `std::hash` (`DefaultHasher`) for change detection.
- Copy text, exact:
  - toasts: `"Reloaded {name}"`, `"{name} was deleted"`, `"Saved {name}"`, `"Couldn't save {name}: {err}"`;
  - banners: deleted `"This file was deleted"` with a `Close Tab` button; conflict `"This file changed on disk"` with `Reload` and `Keep Mine`;
  - find count `"{i} of {n}"`, no results `"No results"`;
  - remote image placeholder `"Remote image · Load"`;
  - unsaved guard: title `"Save changes to {name}?"`, buttons `Save`, `Don't Save`, `Cancel`.
- Image cache bound: **64 entries and 128 MB of decoded RGBA bytes**, LRU. Downscale anything wider than 2 × the column width (`READ_W_WIDE` × 2 = 1920 px) on decode.
- Live reload: debounce **150 ms** per path; watch each open file's **parent dir non-recursively**, each sidebar root **recursively**.
- Edit autosave: none. Saving is explicit. Save writes atomically (write `name.tmp` in the same dir, then `rename`).

## Review Focus

1. **An editor saving by atomic rename** (write temp, rename over) must count as a change, not a delete. Covered by `watch::tests::rename_over_is_change`.
2. **The app's own save must not trigger a reload toast or a conflict banner.** Covered by `edit::tests::own_save_is_not_external_change`, which records the saved hash.
3. **Closing a tab or quitting with unsaved edits** must ask first. Closing the window can't be intercepted in this Rune rev, so quit loses edits; record this in the notes. Covered by `view_tests::close_dirty_tab_asks`.
4. **A find query that matches nothing, or an empty query,** shows `"No results"` / nothing, and Enter does nothing. Covered by `find::tests::empty_and_missing_query`.
5. **An image that fails to decode, or a huge one,** must show a placeholder and never block or blow memory. Covered by `images::tests::cache_evicts_by_bytes` and `images::tests::bad_image_is_none`.

### Task 2: Live reload (§5.5, §4.12)

**Files:** create `src/watch.rs`, `src/watch_tests.rs`. Modify `Cargo.toml` (notify), `src/tabs.rs` (`Tab.changed: bool`, `Tab.deleted: bool`, `Tab.hash: Option<u64>`), `src/app.rs` (`AppState::file_event`), `src/main.rs` (start the watcher in `on_ready`, then keep its watched set in sync from `poll`), `src/ui/document.rs` (deleted banner, 60% dim), `src/ui/titlebar.rs` (6pt accent dot on background tabs with `changed`).

**Interfaces:**
```rust
pub enum FileEvent { Changed(PathBuf), Removed(PathBuf) }
pub struct Watcher { /* notify watcher + debounce thread */ }
impl Watcher {
    pub fn start(on_event: impl Fn(FileEvent) + Send + 'static) -> Result<Watcher, String>;
    pub fn sync(&mut self, files: &[PathBuf], roots: &[PathBuf]);   // watch parents non-recursive + roots recursive; unwatch the rest
}
pub fn debounce(events: &mut Vec<(PathBuf, f64)>, now: f64) -> Vec<PathBuf>;   // pure: paths quiet ≥150 ms
pub fn content_hash(src: &str) -> u64;
impl AppState { pub fn file_event(&mut self, ev: FileEvent); }   // queues Job::Load for open tabs (keeping scroll), marks deleted, rescans a root whose tree changed
```
- On reload, `loaded` compares `content_hash`; equal → nothing visible changes (no toast, no frame). Different → replace the doc, toast `"Reloaded {name}"` only when it's the active tab, else set `changed` (the dot); activating clears it.
- Removed → `deleted = true`, keep the last content dimmed, toast `"{name} was deleted"`. If the file comes back, reload and clear `deleted`.
- A tab in Edit mode with unsaved edits never reloads silently: set `conflict = true` instead (Task 9 shows the banner). For Wave 1, add the field and leave it unused.
- Sidebar roots: on any create/remove/rename under a root, re-queue `Job::Scan` for it (debounced the same way).

Tests: `debounce_waits_150ms`, `rename_over_is_change` (real notify in a tempdir: write `a.md.tmp` then rename over `a.md` → one `Changed(a.md)` within 2 s), `same_content_does_not_toast`, `deleted_then_restored`.

Commit `watch: live reload with debounce, deleted state, changed dot`.
