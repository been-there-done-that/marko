Marko

A small, fast viewer for Markdown. Open a file or a folder, or drop either onto the window.

Everything draws on the GPU: links, bold, italics, inline code, tables, task lists and diagrams. Find marks every highlight match in the document.

Preview comes first. Edit mode arrives later and reuses the same renderer.

Code

rust 
fn main() {
    // Open whatever the shell passed in.
    let paths: Vec<PathBuf> = std::env::args_os().skip(1).map(PathBuf::from).collect();
    Viewer::app(paths).run();
}
